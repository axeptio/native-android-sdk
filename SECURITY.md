# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public channels.

Email **support@axeptio.eu** with:

- the SDK version (`io.axeptio:sdk:<version>`) and Android version affected,
- a description of the issue and its impact,
- steps to reproduce, or a proof of concept.

We will acknowledge your report and keep you informed as we investigate and fix it.

## Supported versions

Only the latest release receives security fixes — see the
[releases page](https://github.com/axeptio/native-android-sdk/releases). Keep your integration on
the most recent version, as required by the [license](LICENSE).
